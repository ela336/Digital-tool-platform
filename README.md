 ## Digital Tool Platform

 Live Demo: https://ela336.github.io/Digital-tool-platform/



##  A Little Description

Digital Tool Platform is a modern web application that provides a collection of useful AI-powered and productivity tools in one place.  
It is designed with a clean UI, responsive layout, and smooth user experience for both mobile and desktop users.



##  Technologies Used

-  React.js
-  Vite
-  Tailwind CSS
-  DaisyUI
-  Lucide React Icons
-  React Toastify



##  Features

-  Fully Responsive Design (Mobile, Tablet, Desktop)
-  Multiple AI & Productivity Tools in one platform
-  Interactive Cart System with real-time counter
-  Modern UI with Tailwind + DaisyUI styling
-  Fast performance using Vite build system
